Core UI is the original ServiceNow interface. It's what the platform looked like in 2004 and it's what most of it still looks like today. Blue banner at the top, application navigator on the left, content area in the middle. It's not flashy, but it works, and every admin spends the bulk of their time here.

The platform administration modules (System Definition, Security, System Properties) only exist in Core UI. You can't configure ACLs from a workspace. You can't build a business rule from Service Portal. This is where the real work happens.

## What's in this section

- **[Forms](/ux/core-ui/forms/)** — The form layout system, form sections, related lists
- **[Lists](/ux/core-ui/lists/)** — List view, personalization, filter conditions
- **[Reports](/ux/core-ui/reports/)** — Platform Analytics, dashboards, data visualization
- **[Client Scripts](/ux/core-ui/client-scripts/)** — JavaScript that runs in the browser on form events

- **[UI Pages](/ux/core-ui/ui-pages/)** — Custom HTML pages rendered with Jelly
- **[Visual Task Boards](/ux/core-ui/visual-task-boards/)** — Kanban-style boards for work management
