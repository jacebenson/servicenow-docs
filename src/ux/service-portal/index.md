Service Portal is the widget-based portal framework that replaced the legacy Content Management System (CMS). Built on AngularJS, it gives you a way to build end-user interfaces — service catalogs, knowledge bases, request tracking — using reusable widgets composed onto pages.

Service Portal is separate from Core UI. You configure it through the `sp_` tables and the Service Portal configuration interface. Each portal has its own theme, widgets, pages, and security settings.

For the full knowledge stack reference:

- [Maik Skoddow - Platform: Service Portal](https://www.servicenow.com/community/service-portal-articles/platform-service-portals-knowledge-amp-troubleshooting-resources/ta-p/2449984)
