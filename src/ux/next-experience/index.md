Next Experience is ServiceNow's modern UI framework. It replaces the old Core UI application navigator with a unified navigation bar, brings web components to the platform, and powers Configurable Workspaces — the agent-facing interfaces for ITSM, CSM, ITOM, and more.

The key pieces are **UI Builder** (visual page assembly), **Configurable Workspaces** (pre-built agent interfaces you can customize), and **UX Lists and Forms** (the new data display layer).

Everything about Next Experience lives in the ServiceNow developer portal:

- [Next Experience UI Framework - Developer Docs](https://developer.servicenow.com/dev.do#!/reference/next-experience/zurich/ui-framework/getting-started/introduction)
