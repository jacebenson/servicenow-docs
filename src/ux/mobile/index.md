ServiceNow's mobile story has evolved significantly. The flagship mobile app, Now Mobile, gives agents and end users access to their workspaces, approvals, and catalog from a phone or tablet. There's also a separate Now Mobile for field service, and Mobile Portal for custom mobile experiences built on Service Portal.

Mobile apps use the same backend as the web interface — same ACLs, same business rules, same notifications. The difference is the front-end rendering pipeline, which optimizes for smaller screens and touch interaction.

For in-depth reference, Maik Skoddow tracks the full mobile knowledge stack:
